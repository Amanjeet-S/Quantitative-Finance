# Stochastic-volatility inference and predictive uncertainty

**Status: optional later extension. No implementation or empirical findings are available.**

This direction would investigate when latent-volatility models improve predictive distributions and risk decisions. The intended progression is a linear Gaussian benchmark, a bootstrap particle filter and a documented estimation method, followed by chronological predictive evaluation using observed returns.

Filtering, smoothing, particle degeneracy and parameter uncertainty require separate treatment. A known synthetic model may support recovery checks only. The empirical dataset and final scope remain undecided. Development follows the [repository roadmap](../../docs/roadmap.md).
