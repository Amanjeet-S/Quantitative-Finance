# Volatility calibration and identifiability

**Status: optional later extension. No calibration results or completed pricing engine are available.**

This direction would ask whether parameter sets fitting option prices almost equally well imply materially different Greeks or values for other contracts. It would connect characteristic-function pricing, Fourier inversion, numerical quadrature and constrained optimisation to identification and quote uncertainty.

Observed option quotes are required for empirical findings. Model-generated surfaces would support parameter-recovery checks only. Integration error, optimisation error, weak identification and misspecification must be distinguished. Historical and risk-neutral probability measures must remain explicit. Development follows the [repository roadmap](../../docs/roadmap.md).
